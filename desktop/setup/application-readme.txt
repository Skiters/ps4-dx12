PS4 Desktop — экспериментальный нативный DirectX 12, 09.10.2026.
Откройте приложение и выберите «Установить PKG». Игры в установщик не включены.
Данные создаются в %LOCALAPPDATA%\PS4Desktop; приложение устанавливается отдельно.
Игры: %LOCALAPPDATA%\PS4Desktop\Games. Сохранения: native-profile\user\home.
DLC: native-profile\user\addcont. Дополнительные собственные PS4-модули и шрифты:
native-profile\user\sys_modules и native-profile\user\fonts.
Приложение использует только DX12; генерация кадров, XeSS и диагностические метрики
отключены. Обычная Windows 11 x64 с аппаратным DX12 и процессором AVX2 необходима.
.NET, Python для установщика PKG и библиотеки MSVC поставляются внутри приложения.
Системные драйверы и компоненты Windows установщик не изменяет.
Важно: меню/PKG проверены, но зависание загрузки игрового мира Bloodborne в текущем
экспериментальном ядре ещё не устранено. Более мощный ПК не заменяет исправление.
Папка данных пользователя сохраняется при удалении приложения.
Для Orbit добавьте установленный PS4Desktop.exe как пользовательское приложение.
